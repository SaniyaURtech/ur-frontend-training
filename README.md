# ShopDesk – Training App

Training project for the UR Technology Frontend Intern Program.
Built with Next.js (App Router), TypeScript and Tailwind CSS.

## Prerequisites

- Node.js LTS (check with `node -v`)
- npm
- Git

## Installation

```bash
git clone https://github.com/SaniyaURtech/ur-frontend-training.git
cd ur-frontend-training
npm install
```

## Run locally

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Other commands

```bash
npm run build   # production build
npm run lint    # run ESLint
```
